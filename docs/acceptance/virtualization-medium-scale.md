# 虚拟化中等规模验收

日期：2026-09-27

## 自动化基线

`src/sidebar-hub/virtualization-acceptance.test.ts` 使用公开接口验证：

- 5,000 页面与 500 数据库仍生成完整的可搜索、可排序条目，但虚拟窗口挂载数不超过向上取整的视口行数加 16。
- 页面引用数量与数据库记录总数只请求虚拟窗口和缓冲范围内的稳定条目 key。
- 1,000 标签节点先按当前树状态拍平，再由同一虚拟窗口限制挂载范围。

完整测试、类型与 Svelte 检查以及生产构建是交付门槛。

## 思源桌面人工验收

以下步骤需要在加载中等规模测试知识库的思源桌面端执行，不能由无桌面运行实例的自动化环境代替：

- [ ] 在页面、数据库和标签面板连续快速滚动，确认没有持续空白区域或明显跳动。
- [ ] 调整侧边栏高度并切换标签页，确认窗口会重新测量且各面板保留自己的滚动位置。
- [ ] 分别执行搜索、切换排序字段与方向并刷新，确认搜索和排序回到顶部，刷新恢复首个可见条目附近。
- [ ] 观察页面和数据库计数，确认只在条目进入可见范围附近后出现；滚动离开再返回不重复闪烁为未知状态。
- [ ] 展开、折叠和搜索标签，清空搜索后确认恢复搜索前的折叠状态；“展开全部”和“折叠全部”作用于完整标签树。
- [ ] 在页面虚拟行使用右键菜单完成重命名、属性查看和取消删除操作。
- [ ] 抽查书签、日历、日记导航和已有偏好格式，确认行为未改变。
