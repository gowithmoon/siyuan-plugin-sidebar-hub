# 沿用思源原生的书签归属模型

状态：已接受
日期：2026-09-28

侧边栏中枢的书签编辑沿用思源原生块属性所定义的单值书签归属，插件不另建多值关联或独立的持久化书签分组。将对象拖入目标分组会替换其原有书签归属，仅作用于实际拖入的文档块或内容块；不移动内容，不递归修改子块。分组由现有归属派生，最后一个成员离开后自然消失。

这一边界使插件与原生书签面板共享同一份归属数据，并避免维护两套分组及同步规则。代价是无法让同一块同时属于多个书签，也不能保留没有成员的固定分组；这些能力若以后需要引入，必须重新评估数据所有权与原生兼容性。

书签条目的菜单按目标类型分流：文档复用页面的重命名、属性和删除文档动作，另提供移除书签；普通内容块只提供块属性和移除书签，避免把文档级 API 误用于内容块。
